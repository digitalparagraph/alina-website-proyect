# Social kit — Alina Martínez

Recreation of the live Instagram/Facebook post system, taken from the 2025–2026 `Parrillas RRSS` artwork
(`Alina Martínez/2026/Parrillas RRSS/07. Julio/Bajadas/...`) and the sales campaign (`2026/Campañas`).

| File | Format |
| --- | --- |
| `QuotePost.jsx` | Butter field, logo, centred light quote with an optional bold/brush opener |
| `IllustrationPost.jsx` | Quote + packaged line-art figure on the hairline ground rule |
| `PhotoAdPost.jsx` | Photograph with stacked butter marker capsules + outlined CTA (paid campaign) |
| `CarouselPost.jsx` | Carousel opener: drawn arc, brush stroke behind the bold title, floating quotes |

All artboards are 1080 × 1350 (the working size in the Illustrator/Photoshop sources). Stories use 1080 × 1920
with the same rules. `index.html` scales the artboard to 60% for preview.
