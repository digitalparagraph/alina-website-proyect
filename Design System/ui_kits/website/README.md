# Website kit — Alina Martínez (directional)

**Disclaimer:** the site does not exist yet. The only source material is
`Alina Martínez/2026/Sitio Web/Moodboard/Alina_Website_Moodboard.pdf`, whose direction reads:
clean layout · clear, hierarchical information · photography that highlights human connection ·
combinations with organic/dynamic elements. The `05. Sitio Web` / `Copies y estructura` folders were
empty or Google-Docs links this run, so section copy is reused verbatim from the campaign decks
("Plantea la vida planeada", "Conecta contigo mismo, agenda una sesión y reinicia tu vida.",
"Resuelve los temas que tienes pendientes y comienza a crecer", "Cada una de tus decisiones importa").
Everything here follows the brand's existing print/social language — it is **not** a recreation of a live site.
