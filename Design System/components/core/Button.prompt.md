Pill button for any action; `primary` (butter) is the default CTA, `secondary` is the hairline outline used over photos and butter fields.

```jsx
<Button variant="primary" size="lg">Agenda tu sesión</Button>
<Button variant="secondary">Conoce más</Button>
```

Variants: primary · secondary · lilac · ghost · inverse. Sizes sm/md/lg. Hover lightens one step, press scales to 98.5%. Never add a drop shadow.
